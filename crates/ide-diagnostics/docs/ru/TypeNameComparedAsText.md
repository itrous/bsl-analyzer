# Сравнение с текстом имени типа (TypeNameComparedAsText)

## Описание диагностики

Выражение `Строка(ТипЗнч(Значение))` превращает имя типа в текст, а этот текст зависит от языка интерфейса: у одного и того же значения он разный в русском и английском интерфейсе. Если по такому тексту принимается решение, то при смене языка условие молча перестаёт срабатывать: ошибки нет, просто нужная ветка больше не выполняется.

Платформа этого не ловит: сравнение выполняется без ошибки и на языке разработчика даёт ожидаемый результат. Это замечание по стандартам кода, а не ошибка времени выполнения.

Правильно сравнивать типы через `Тип()`: `ТипЗнч(Значение) = Тип("СправочникСсылка.Номенклатура")`. Такое сравнение от языка интерфейса не зависит.

Диагностика срабатывает, когда имя типа СРАВНИВАЕТСЯ СО СТРОКОВЫМ ЛИТЕРАЛОМ. Нужны все три части: имя типа в виде текста, сравнение и литерал с другой стороны. Литерал - это строка в тексте, `НСтр("...")` или локальная переменная, которой в этой процедуре присваиваются только строковые литералы; параметр, переменная неизвестного происхождения или иное выражение литералом не считаются (тогда сравнение может быть сравнением типа с типом).

- Имя типа - это `Строка(ТипЗнч(...))` (`String(TypeOf(...))`), написанное на месте либо взятое из локальной переменной, которой в этой процедуре присваивается только такой вызов (один уровень переменной; если переменной присваивается и что-то другое, замечания нет).
- Имя могут оборачивать `Лев`, `Прав`, `СокрЛП`, `СокрЛ`, `СокрП`, `ВРег`, `НРег`, `СтрДлина` в любой вложенности.
- Сравнение - это `=` или `<>` со строковым литералом с любой стороны, `Найти(имя, "литерал")`, сравниваемое с любым числовым литералом (`> 0`, `= 1`, `<> 0` и т. п., число с любой стороны), `СтрНачинаетсяС` и `СтрЗаканчиваетсяНа` с литералом.

Замечание ставится на вызов `Строка(...)`, если он написан на месте, и на сравнение, если имя пришло через переменную.

Не отмечается имя типа, которое просто выводится, пишется в журнал, попадает в текст исключения, склеивается, возвращается или сохраняется: в этих случаях от текста ничего не зависит. Не отмечается и сравнение с другим именем типа или с переменной, а не с литералом.

## Примеры

Неправильно:

```bsl
Если Строка(ТипЗнч(Значение)) = "СправочникСсылка.Номенклатура" Тогда
    ОбработатьНоменклатуру(Значение);
КонецЕсли;
```

То же через переменную (тоже отмечается):

```bsl
Имя = Строка(ТипЗнч(Объект));
Если Лев(Имя, 24) = "Внешняя обработка объект" Тогда
```

Правильно:

```bsl
Если ТипЗнч(Значение) = Тип("СправочникСсылка.Номенклатура") Тогда
    ОбработатьНоменклатуру(Значение);
КонецЕсли;
```

Не отмечается (имя типа только выводится человеку):

```bsl
ВызватьИсключение "Неожиданный тип: " + Строка(ТипЗнч(Значение));
```
