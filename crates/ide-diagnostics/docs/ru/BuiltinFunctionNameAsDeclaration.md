# Имя встроенной функции как имя объявляемой функции (BuiltinFunctionNameAsDeclaration)

## Описание диагностики

Компилятор 1С:Предприятие 8.3.27.2074 отвергает объявление функции с именем
встроенной функции `Найти` сообщением «Ожидается имя функции», и конфигурация
не запускается. Диагностика сообщает об этом до запуска и выделяет имя в
объявлении функции.

По умолчанию правило включено и имеет тип «Ошибка» с важностью `Blocker`: в
редакторе находка показывается как ошибка. Уровень и отключение настраиваются
штатно, как у остальных правил.

Границы правила:

- проверяется ровно одна пара имён: `Найти` и `Find`, без учёта регистра
  (`нАйТи`, `fInD` тоже отмечаются); сообщение сохраняет имя в исходном
  написании;
- проверяются только объявления функций. Процедуры `Найти`/`Find`, переменные и
  параметры правило не отмечает;
- `Экспорт`, параметры и тело функции на проверку не влияют;
- правило не зависит от вида модуля, среды выполнения, версии платформы из
  настроек проекта и загруженной справки платформы: оно срабатывает и в обычном
  файле без метаданных;
- вызовы `Найти(...)` и методы коллекций `Массив.Найти(...)` не отмечаются;
- другие встроенные функции (`СтрНайти`, `StrFind` и прочие) и имена,
  начинающиеся с `Найти`, не отмечаются: правило не объявляет зарезервированной
  всю поверхность платформы.

## Примеры

Неправильно — компилятор отвергает объявление:

```bsl
Функция Найти(Значение) Экспорт
    Возврат Значение;
КонецФункции
```

Правильно — имя функции не совпадает со встроенной функцией:

```bsl
Функция ПолучитьЗначение(Значение) Экспорт
    Возврат Значение;
КонецФункции
```

Правильно — вызов метода коллекции `Найти` внутри функции с другим именем:

```bsl
Функция ИндексВМассиве(Массив, Значение) Экспорт
    Возврат Массив.Найти(Значение);
КонецФункции
```

## Доказательность

- Отказ компилятора наблюдался на объявлении `Функция Найти(Значение) Экспорт` в
  неглобальном общем модуле (`Global=false`, `Server=true`,
  `ExternalConnection=true`) на платформе 8.3.27.2074 — см. issue.
- `Find` — английское имя той же встроенной функции. Запрет на `Find`, на другие
  варианты регистра, на другие виды модулей и версии платформы принят по
  аналогии, отдельным наблюдением компилятора не подтверждён.
- Процедуры и другие встроенные имена правило не проверяет потому, что для них
  нет наблюдений, а не потому, что компилятор их принимает.
- Стандарт разработки 1С, запрещающий такое имя, не найден; правило ссылается на
  наблюдение компилятора, а не на стандарт.
