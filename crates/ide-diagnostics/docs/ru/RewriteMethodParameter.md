# Перезапись параметров метода (RewriteMethodParameter)

## Описание диагностики

Если параметр процедуры или функции перезаписывается в самом начале тела метода, до какого-либо использования его значения, это вводит в заблуждение вызывающий код: передаваемый аргумент фактически игнорируется. Такой параметр следует либо убрать из сигнатуры, преобразовав в локальную переменную, либо переименовать для ясности.

Текущая реализация уже и точнее, чем простой текстовый поиск:

- проверяются только параметры, переданные по значению (`Знач`);
- для target внутри `Пока` проверяется достижимый путь от входа метода: первая слепая запись не скрывается определениями с обратной дуги цикла, а предшествующая реальная запись на том же пути подавляет повторную находку; заголовки внешних `Для` и `Для Каждого` учитываются как запись их переменной;
- диагностика не срабатывает, если параметр прочитан в правой части или в любом операторе, выполняемом до перезаписи, — включая условие объемлющего `Если`/`Пока`/заголовка цикла (идиом инициализации дефолта `Если Параметр = Неопределено Тогда Параметр = …` ошибкой *не* считается);
- самоприсваивания вида `Парам = Парам` пропускаются и не считаются осмысленным использованием;
- недостижимая запись после `Прервать` или `Продолжить` не диагностируется;
- для target вне `Пока` сохраняется прежняя проверка reaching definitions;
- имена параметров сравниваются без учёта регистра, включая кириллицу.

## Примеры

Подозрительный код

```bsl
Функция СформироватьОтчёт(Знач ПутьКФайлу, Знач Формат = "xlsx") Экспорт
  ПутьКФайлу = КаталогОтчётов() + "итоги.xlsx"; // параметр перезаписан
  // ...
КонецФункции
```

Исправленный вариант — параметр убран, используется локальная переменная

```bsl
Функция СформироватьОтчёт(Знач Формат = "xlsx") Экспорт
  ПутьКФайлу = КаталогОтчётов() + "итоги.xlsx";
  // ...
КонецФункции
```

Или параметр используется по назначению

```bsl
Функция СформироватьОтчёт(Знач ПутьКФайлу, Знач Формат = "xlsx") Экспорт
  Если ПустаяСтрока(ПутьКФайлу) Тогда
    ИтоговыйПуть = КаталогОтчётов() + "итоги.xlsx";
  Иначе
    ИтоговыйПуть = ПутьКФайлу;
  КонецЕсли;
  // ...
КонецФункции
```
