# Присваивание значения свойству, доступному только для чтения

Диагностика срабатывает на оператор присваивания, в котором левая часть — доступ к свойству платформенного типа, помеченному как доступное только для чтения (например, `Запрос.Параметры`, `РезультатЗапроса.Колонки`).

Признак «только чтение» берётся из данных о платформе. Основной источник — справка платформы (`Использование: Только чтение`), но не единственный: если страница справки метку не несёт, а платформа запись запрещает, факт восстанавливается поправкой в `platform_overlays.json` (`type_property_corrections`, см. `crates/bsl-platform/data/OVERLAYS.md`). Так исправлено, например, `ОбластьЯчеекТабличногоДокумента.Значение`.

## Почему это проблема

Такое присваивание выполнится молча на этапе разбора, но во время выполнения приведёт либо к исключению, либо просто не окажет никакого эффекта на объект. Обычно корректный способ задать значение — использовать специальный метод менеджера (`УстановитьПараметр` для параметров запроса) или пересобрать объект целиком.

## Примеры

Неправильно:

```bsl
Зап = Новый Запрос;
Зап.Параметры = Новый Структура; // <-- свойство только для чтения
```

Правильно:

```bsl
Зап = Новый Запрос;
Зап.УстановитьПараметр("Ключ", Значение);
```

## Отключение

Если справка платформы для конкретного свойства устарела, или диагностика срабатывает на корректном коде, её можно отключить стандартным образом в настройках анализатора.
