# Итератор совпадает с коллекцией (IteratorCollidesCollection)

## Описание диагностики

В цикле `Для Каждого <Итератор> Из <Коллекция> Цикл` переменная обхода и обходимая коллекция записаны одним и тем же именем. Это одна и та же переменная: после первой итерации в неё записывается элемент, и значение, которое было коллекцией, теряется. Условие отличается от `UseLessForEach`: итератор может использоваться в теле цикла, но коллекция всё равно перезаписывается.

Диагностика срабатывает на переменную обхода, если источник обхода — неквалифицированный идентификатор, совпадающий с итератором без учёта регистра; скобки вокруг идентификатора (`(Коллекция)`) источник не меняют. Модульные переменные не исключаются: перезапись модульной переменной-коллекции тоже ошибка.

Не считаются совпадением:

- квалифицированный источник (`Объект.Коллекция`): имя свойства другого объекта — не та же переменная;
- источник — вызов, индексация или любое другое выражение;
- копия коллекции в другой переменной (`Б = А`, затем `Для Каждого А Из Б`): это разные переменные.

## Примеры

Неправильно:

```bsl
Коллекция = Новый Массив;
Коллекция.Добавить(1);
Для Каждого Коллекция Из Коллекция Цикл
    Сообщить(Коллекция);
КонецЦикла;
```

Правильно:

```bsl
Коллекция = Новый Массив;
Коллекция.Добавить(1);
Для Каждого Элемент Из Коллекция Цикл
    Сообщить(Элемент);
КонецЦикла;
```
