# Ключ структуры не является идентификатором (StructureKeyIsNotIdentifier)

## Описание диагностики

Ключ структуры обязан быть идентификатором: буква (латинская или кириллическая) или `_` в начале, дальше буквы, цифры и `_`; одиночное `_` допустимо. Любая другая строка (с точкой, пробелом, дефисом, цифрой в начале) платформа отвергает во время выполнения.

Замер на платформе 8.3.27.2214:

- Конструктор `Новый Структура` принимает СПИСОК ключей через запятую. Пробелы вокруг каждого ключа отбрасываются, пустая запись пропускается: `Новый Структура("а, б")`, `("а,б")`, `(" а , б ")`, `("а,, б")` и `("а,")` приняты, ключи `а` и `б`. Пустой литерал `Новый Структура("")` допустим и даёт структуру без ключей, он никогда не отмечается.
- `Новый Структура("а.б")`, `("а б")`, `("а-б")`, `("1а")` и `("а, б в")` дают отказ «Ошибка при вызове конструктора (Структура): Недопустимое значение параметра (параметр номер '1')».
- Методы `Вставить`, `Свойство` и `Удалить` принимают ОДИН ключ без разбиения по запятой и без пустого ключа; пробельные символы (пробел, табуляция, неразрывный пробел, перевод строки) вокруг ключа отбрасываются: `Вставить("а ")` и `Вставить(" а")` приняты с ключом `а`, а ключ из одних пробелов равен пустому. `Вставить("а.б")`, `("а б")`, `("а-б")`, `("1а")`, `("а, б")`, `("")` и `("   ")` дают отказ «Ошибка при вызове метода контекста (Вставить): Задано неправильное имя атрибута структуры»; для `Свойство` и `Удалить` отказ тот же, с именем своего метода.
- Принимаются `_а`, `а_1`, `Name1`, одиночное `_` и `ЁЙ`.

`Соответствие` ключи не ограничивает: `Новый Соответствие` и `Соответствие.Вставить("а.б", 1)` допустимы и очень распространены, поэтому методы проверяются только у получателя, тип которого определён как `Структура` или `ФиксированнаяСтруктура`. У `ФиксированнаяСтруктура` методов `Вставить` и `Удалить` нет, поэтому у неё проверяется только `Свойство`. Получатель неизвестного типа, `Соответствие` и любой другой тип не отмечаются.

Диагностика срабатывает на строковый литерал-ключ, по одному разу на вызов: для конструктора - когда хотя бы одна непустая запись списка (после отбрасывания пробелов) не является идентификатором. Ключ из переменной или выражения статически неизвестен и не отмечается.

## Примеры

Неправильно:

```bsl
Параметры = Новый Структура("Код.Номенклатуры, Количество");
Параметры.Вставить("Цена за единицу", 1);
```

Правильно:

```bsl
Параметры = Новый Структура("КодНоменклатуры, Количество");
Параметры.Вставить("ЦенаЗаЕдиницу", 1);
```
