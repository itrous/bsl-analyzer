# Использование метода ПолучитьФорму (GetFormMethod)

## Описание диагностики

Стандарт `#std487` («Минимизация количества серверных вызовов и трафика»),
п. 4.1, требует при открытии формы из кода открывать её за один вызов методом
глобального контекста `ОткрытьФорму`. Если форма сначала получается через
`ПолучитьФорму`, а затем открывается вручную, на это уходит лишний серверный
вызов.

Сам по себе вызов `ПолучитьФорму` работает и возвращает объект формы; стандарт
не запрещает получать форму, например, ради навигационной ссылки, печати или
проверки компиляции формы. Для таких случаев `ОткрытьФорму` не подходит: она
открывает окно, а `ПолучитьФорму` — нет. Диагностика намеренно строже текста
стандарта: она срабатывает на любой прямой вызов `ПолучитьФорму` / `GetForm`,
включая объектные методы, а не только на последовательность
`ПолучитьФорму(...); ...Открыть()`, поэтому там, где форму не нужно
открывать, замечание можно отключить.

## Примеры

Неправильно:
```bsl
Процедура ОткрытьКарточкуТовара()
    Товар = Справочники.Номенклатура.НайтиПоКоду("00001");
    Форма = Товар.ПолучитьФорму("ФормаЭлемента");
КонецПроцедуры
```

```bsl
Процедура ОткрытьНастройки()
    ФормаНастроек = ПолучитьФорму("Обработка.НастройкиПрограммы.Форма");
КонецПроцедуры
```

Правильно:
```bsl
Процедура ОткрытьКарточкуТовара()
    Товар = Справочники.Номенклатура.НайтиПоКоду("00001");
    ОткрытьФорму("Справочник.Номенклатура.ФормаОбъекта", Новый Структура("Ключ", Товар));
КонецПроцедуры
```
