# Функция не найдена в языке запросов (UnknownQueryFunction)

## Описание диагностики

Диагностика сообщает о запросе, который вызывает функцию, отсутствующую в языке запросов 1С, например `ПОДСТРКА` вместо `ПОДСТРОКА`.

Имя считается неизвестным только тогда, когда лексер языка запросов не узнаёт его ни как функцию, ни как виртуальную таблицу, ни как ключевое слово или тип. Настоящие функции не отмечаются никогда, в том числе те, которые анализатор не моделирует отдельно (`СокрЛП`, `Цел`, `Окр`, `Sqrt`, `Лев`, `Прав`, `УНИКАЛЬНЫЙИДЕНТИФИКАТОР`, `ПРЕДСТАВЛЕНИЕССЫЛКИ`).

## Примеры

Опечатка в имени функции:
```sdbl
ВЫБРАТЬ
	ПОДСТРКА(Товары.Наименование, 1, 2) КАК Краткое
ИЗ
	Справочник.Товары КАК Товары
```
