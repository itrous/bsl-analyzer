# Несоответствие индексов и условий запроса (QueryConditionWithoutIndex)

## Описание диагностики

Диагностика выявляет условие в параметрах виртуальной таблицы регистра накопления
(`Остатки`, `Обороты`, `ОстаткиИОбороты`), поля которого не покрываются индексом таблицы
итогов.

Для таблиц итогов регистра накопления платформа строит основной индекс: измерения в порядке
их следования в конфигурации. Измерение, для которого в метаданных включено индексирование,
дополнительно получает собственный индекс: сначала это измерение, затем все остальные
измерения в порядке следования в конфигурации. Условие использует индекс, только если его
поля — это ровно первые поля одного из индексов. Иначе выборка из таблицы итогов выполняется
полным просмотром.

Срабатывает, когда выполнены все условия:

- условие в параметрах виртуальной таблицы регистра накопления — это конъюнкция (`И`)
  сравнений на равенство `<поле> = <выражение>`; поле записано без источника или с
  псевдонимом источника;
- все поля условия — измерения этого регистра;
- ни один индекс не начинается ровно с набора измерений условия.

Период в проверке не участвует: запрос без периода с условием по начальным измерениям
считается оптимальным.

В сообщении указано первое по порядку измерение, которое отсутствует в условии, хотя
последующее присутствует.

Не срабатывает:

- на условиях, которые диагностика не может оценить: `ИЛИ`, `В`, `НЕ`, сравнения `>`,
  `<`, `>=`, `<=`, `<>`, `МЕЖДУ`, `ЕСТЬ NULL`, `ВЫБОР`, вложенный запрос, функция от поля;
- на условии с полем, которое не является измерением регистра (ресурс, реквизит, неизвестное имя);
- на пустом параметре условия;
- на регистрах сведений, бухгалтерии и расчёта;
- на условиях в `ГДЕ` и в `ПО` соединения.

## Примеры

Неправильно (регистр `ТоварыНаСкладах` с измерениями `Склад`, `Номенклатура`, `Качество`,
индексирование не включено ни у одного):

```bsl
ВЫБРАТЬ
    Остатки.КоличествоОстаток КАК Количество
ИЗ
    РегистрНакопления.ТоварыНаСкладах.Остатки(, Номенклатура = &Номенклатура) КАК Остатки
```

```bsl
ВЫБРАТЬ
    Остатки.КоличествоОстаток КАК Количество
ИЗ
    РегистрНакопления.ТоварыНаСкладах.Остатки(, Склад = &Склад И Качество = &Качество) КАК Остатки
```

Правильно (условие по начальным измерениям подряд):

```bsl
ВЫБРАТЬ
    Остатки.КоличествоОстаток КАК Количество
ИЗ
    РегистрНакопления.ТоварыНаСкладах.Остатки(, Склад = &Склад И Номенклатура = &Номенклатура) КАК Остатки
```

Правильно (у измерения `Номенклатура` включено индексирование: условие по нему вместе с
начальными измерениями остальных):

```bsl
ВЫБРАТЬ
    Остатки.КоличествоОстаток КАК Количество
ИЗ
    РегистрНакопления.ТоварыНаСкладах.Остатки(, Номенклатура = &Номенклатура И Склад = &Склад) КАК Остатки
```

Либо в конфигурации изменён порядок измерений.
