# Обращение к неизвестному полю (UnresolvedField)

## Описание диагностики

Диагностика сообщает об обращении к полю выражения, тип которого известен достаточно точно, чтобы анализатор мог уверенно сказать: такого поля у этого типа нет.

Обычно это означает одно из следующих:

- в имени поля есть опечатка;
- код ожидает другой тип объекта метаданных;
- выражение на самом деле может иметь другой тип или быть `Неопределено`, но это не отражено в коде явно.

Текущая реализация консервативна. Она срабатывает только там, где inference уже получил уверенный metadata-based тип и lookup поля для этого типа завершился неуспешно.

Тип возврата функции из документации («Возвращаемое значение»), называющий объект метаданных — сам или как элемент `Массив из`, — сверяется с телом функции. Если тело возвращает значение другого типа (например, `Структура`), результат вызова имеет оба типа, и его поля не сообщаются. Документированный объект, которого нет в видимой конфигурации, не учитывается. Если тело возвращает документированный объект или ничего определённого, документированный тип остаётся закрытым, и отсутствующее поле по-прежнему сообщается.

Поле, прочитанное через локальную переменную, сообщается, только если каждая запись, достигающая чтения, даёт переменной объект метаданных без этого поля (или `Неопределено`). Переменная, которой в ветках `Если`/`ИначеЕсли` присвоены объекты разных видов, молчит о поле, которое есть хотя бы у одного из них; молчит и тогда, когда среди записей есть параметр, объявление или элемент цикла по неизвестной коллекции.


Коллекции метаданных проверяются так же:

- `Метаданные.Справочники.НетТакого` — объекта с таким именем нет в конфигурации. Модуль компилируется, а при выполнении платформа отвечает «Поле объекта не обнаружено». Проверяются коллекции видов с менеджером (справочники, документы, регистры, планы, перечисления, планы обмена, константы, обработки, отчёты, бизнес-процессы, задачи) — те же виды, чья коллекция менеджеров (`Справочники.НетТакого`) уже проверяется, — и только когда конфигурация видна анализатору; во внешней обработке такое обращение молчит.
- `Метаданные.Справочники.Товары.ПредопределенныеЗначения` — у описания справочника нет такого свойства. Платформа отвечает «Поле объекта не обнаружено» во время выполнения. Проверяются описания объектов с менеджером (справочники, документы, регистры, планы, перечисления, планы обмена, константы, обработки, отчёты, бизнес-процессы, задачи) — для них список свойств платформы проверен на полноту. Свойство проверяется и в цепочке прямо в выражении (`Метаданные.Справочники.Товары.<член>`), и через переменную, в том числе переменную цикла `Для Каждого Описание Из Метаданные.Справочники`, — если на каждом пути к обращению переменная держит описание с закрытым списком свойств и ни у одного из них этого свойства нет. То же относится к переменной, через которую получено описание (`Коллекция.Товары.<член>`, `Для Каждого Описание Из Коллекция`). Если хотя бы на одном пути значение неизвестно (`Описание = Метаданные[Вид][Имя]`, параметр, ветка `Если`, обратная дуга цикла, переменная после цикла по ней же) или переменную можно переписать там, где анализ этого не видит (переменная, переданная аргументом вызова, — аргументы передаются по ссылке, тело с `Выполнить`, запись внутри `Попытка`, прочитанная в обработчике или после него), проверка молчит. Описания вложенных объектов (`Реквизиты.X`, формы, макеты) и результат `Метаданные.НайтиПоПолномуИмени(...)` не проверяются.

Платформенные типы проверяются только там, где полнота состава их членов подтверждена аттестацией (`type_member_surface_attestations` в `crates/bsl-platform/data/platform_overlays.json`):

- тип должен быть в списке аттестованных, а версия данных о платформе, которой пользуется анализатор, — не старше версии, на которой состав проверялся. Если версию данных определить нельзя, проверка молчит;
- для остальных платформенных типов промах ничего не доказывает: полнота извлечения из справки не гарантирована (у части типов состав членов пуст, отдельные страницы в архиве отсутствуют, а имя типа может быть тёзкой), поэтому обращение к неизвестному полю молчит.

```bsl
ТабДок = Новый ТабличныйДокумент;
Область = ТабДок.ТекущаяОбласть;
Нет = Область.ТекущаяОбласть; // <-- у области ячеек такого поля нет
```

Таблица значений, на каждом пути созданная конструктором `Новый ТаблицаЗначений`, считается аттестованным типом `ТаблицаЗначений`; её колонки — члены строк, а не самой таблицы.

## Примеры

Неправильно:

```bsl
Ссылка = ОбщийМодуль.ПолучитьСсылку();
Наименование = Ссылка.НесуществующееПоле;
```

Правильно:

```bsl
Ссылка = ОбщийМодуль.ПолучитьСсылку();
Наименование = Ссылка.Наименование;
```
