# Вызов метода с запросом в цикле (LocalCallWithQueryInCycle)

## Описание диагностики

Диагностика отмечает вызов локального метода этого же модуля в теле цикла, если из вызываемого
метода достижимо выполнение запроса: напрямую или через цепочку других локальных методов. Каждая
итерация цикла может порождать обращение к СУБД, поэтому необходимые данные следует получить одним
запросом до цикла.

Находка ставится на САМ ВЫЗОВ в теле цикла. Выполнение запроса внутри вызываемого метода
отдельно отмечает диагностика `CreateQueryInCycle`, если оно находится в теле цикла лексически.
Цепочка вызовов может быть любой длины и проходит только через методы этого же модуля.

Неправильно:

```bsl
Функция НайтиПоЗначению(Значение)
    Запрос = Новый Запрос("ВЫБРАТЬ 1 КАК Поле");
    Запрос.УстановитьПараметр("Значение", Значение);
    Выборка = Запрос.Выполнить().Выбрать();
    Возврат ?(Выборка.Следующий(), Выборка.Поле, Неопределено);
КонецФункции

Процедура ЗаполнитьСтроки(Таблица, Чтение)
    Пока Чтение.Прочитать() Цикл
        НоваяСтрока = Таблица.Добавить();
        НоваяСтрока.Поле = НайтиПоЗначению(Чтение.Значение);
    КонецЦикла;
КонецПроцедуры
```

Правильно:

```bsl
Процедура ЗаполнитьСтроки(Таблица, Значения)
    Запрос = Новый Запрос("ВЫБРАТЬ Т.Код КАК Значение, Т.Наименование КАК Поле ИЗ Справочник.Товары КАК Т ГДЕ Т.Код В (&Значения)");
    Запрос.УстановитьПараметр("Значения", Значения);
    Выборка = Запрос.Выполнить().Выбрать();

    Пока Выборка.Следующий() Цикл
        НоваяСтрока = Таблица.Добавить();
        НоваяСтрока.Поле = Выборка.Поле;
    КонецЦикла;
КонецПроцедуры
```

## Границы анализа

Это кандидат по достижимости, а не доказанный запрос на каждой итерации: вызываемый метод может
достигать выполнения запроса не на всех путях (например, только по условию). Поэтому важность
ниже, чем у прямого выполнения запроса в цикле (`CreateQueryInCycle`), и совпадает с
`ImplicitDatabaseReadInCycle`.

Правило смотрит только на один модуль. Находки нет, если вызываемый метод принадлежит другому
модулю, если вызов не удалось разрешить или если вызов выполняется по строке. Подавление выполнения
запроса в вызываемом методе директивой `CreateQueryInCycle` снимает и находки по цепочкам,
основанным только на нём.
