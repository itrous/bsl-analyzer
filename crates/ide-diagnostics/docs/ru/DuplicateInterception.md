# Повторный перехват метода (DuplicateInterception)

Предупреждает о повторе одного вида перехвата одного целевого метода внутри
одного физического модуля расширения. Отмечаются имена обоих перехватчиков.

```bsl
&После("ПередЗаписью")
Процедура ЗаполнитьДанные()
КонецПроцедуры

&После("ПередЗаписью")
Процедура ЗаписатьИсторию()
КонецПроцедуры
```

Проверьте оба действия и при необходимости объедините их в одном перехватчике.
Автоматического исправления нет: анализатор не выбирает порядок выполнения и не
удаляет код.

Для сравнения используются целевой метод, вид аннотации и исходный модуль.
Регистр и русское/английское написание аннотации не различаются. Разные цели,
разные виды перехвата и разные модули не считаются одним повтором. Подтверждённо
взаимоисключающие условия компиляции не конфликтуют; неизвестные условия не
угадываются.

Предупреждение не утверждает, что загрузка или применение расширения обязательно
завершится ошибкой. Результат выполнения перехватчиков нужно проверять на целевой
платформе отдельно.
