# Повторное объявление метода (DuplicateMethodDeclaration)

Сообщает о процедурах или функциях одного физического модуля с одинаковым именем,
которые одновременно существуют в подтверждённом контексте компиляции.
Регистр букв не различается. Число параметров и различие между процедурой и
функцией не создают перегрузку. Проверка применяется и к модулям внешних обработок
и отчётов.

```bsl
Процедура Применить(Область, ИмяФИО)
КонецПроцедуры

Процедура Применить(Область, Подразделение, ИмяФИО)
КонецПроцедуры
```

Оба объявления отмечаются ошибкой. Нужно объединить их в один метод либо дать
разным операциям разные имена. Автоматического исправления нет: удаление одного
из объявлений может изменить поведение.

Имена в разных модулях не конфликтуют. Подтверждённо взаимоисключающие ветки
условной компиляции и допустимые разные клиентские и серверные контексты также
не считаются конфликтом. Неопределённые условия не принимаются за доказательство
совместного существования методов. Переменные относятся к другой области имён.

Проверка сравнивает исходные объявления одного файла. Метод расширения и
переопределяемый им метод основной конфигурации не образуют повторное объявление
одного физического модуля.

Это отдельная ошибка полного анализа модуля. Отсутствие `ParseError` само по себе
не означает, что модуль проходит проверку компиляции.
