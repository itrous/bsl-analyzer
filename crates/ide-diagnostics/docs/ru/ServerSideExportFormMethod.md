# Серверный экспортный метод формы (ServerSideExportFormMethod)

## Описание диагностики

Экспортные методы управляемой формы должны оставаться клиентскими. На практике внешний доступ к форме идёт через `ПолучитьФорму`, поэтому экспортные процедуры и функции формы имеют смысл только в клиентском контексте.

Текущая реализация диагностики сообщает о проблеме, если экспортная процедура или функция управляемой формы не имеет директивы `&НаКлиенте`.

Ошибкой считаются как серверные директивы `&НаСервере` и `&НаСервереБезКонтекста`, так и полное отсутствие директивы.

Исключение — методы, имя которых начинается с `Подключаемый_` или `Attachable_` (без учёта регистра): это обработчики подключаемых команд БСП, их вызывают по имени из клиентского общего модуля на переданной форме, и без `Экспорт` такой вызов не работает.

## Примеры

Неправильно

```bsl
&НаСервере
Процедура ОбработатьДанные() Экспорт
    // ...
КонецПроцедуры

&НаСервереБезКонтекста
Функция ВычислитьИтог() Экспорт
    // ...
КонецФункции
```

Правильно

```bsl
&НаКлиенте
Процедура ОбработатьОповещение() Экспорт
    // доступно для вызова из другой формы
КонецПроцедуры
```
