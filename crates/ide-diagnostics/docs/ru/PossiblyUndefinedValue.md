# Значение может быть Неопределено (PossiblyUndefinedValue)

## Описание диагностики

Слабая подсказка: аргумент вызова на одной ветви кода получает значение нужного типа, а на другой остаётся `Неопределено`, которое параметр не принимает.

Код не обязательно ошибочен: значение, равное `Неопределено` на одной из ветвей, - законный BSL. Подсказка лишь указывает место, где вызов завершится ошибкой, если выполнение пойдёт по этой ветви.

### Когда срабатывает

`TypeMismatch` молчит, если ожидаемый и выведенный наборы типов пересекаются: какое-то значение выражения параметру подходит. Из этого правила `PossiblyUndefinedValue` выделяет один случай - выведенный набор содержит `Неопределено`, а ожидаемый его не содержит.

### Ключевые правила

- **Решение по типу, а не по тексту**: наличие `Неопределено` определяется по типу выражения, а не по отображаемому названию, поэтому правило не зависит от языка интерфейса.
- **Параметр принимает `Неопределено`**: диагностика не срабатывает, если ожидаемый набор сам содержит `Неопределено`.
- **Непересекающиеся типы**: если наборы не пересекаются, действует `TypeMismatch`, а не эта подсказка.
- **Пересечение без `Неопределено`**: остаётся полностью тихим.

## Примеры

```bsl
Процедура Тест(Условие)
    Позиция = Неопределено;
    Если Условие Тогда
        Позиция = 5;
    КонецЕсли;
    // Лев ожидает Число, Позиция - Число | Неопределено
    Результат = Лев("abc", Позиция);
КонецПроцедуры
```
