# Опечатка (Typo)

## Описание диагностики

Эта диагностика не является полноценной проверкой орфографии.

Текущая реализация — это только грубая словарная эвристика на базе Hunspell:

- проверяются отдельные идентификаторы и строковые литералы;
- camelCase-идентификаторы разбиваются на составные слова;
- в идентификаторах проверяются имена процедур и функций, параметры, переменные и левая часть присваивания; остальные употребления идентификатора не проверяются;
- диапазон каждой находки указывает на слово в исходном тексте, включая кавычки и все части многострочного литерала;
- используется встроенный набор русских и английских словарей;
- поверх словарей есть большой список исключений для подавления ложных срабатываний;
- пользователь может добавить свои слова в ignore-list.

Такой подход помогает ловить лишь часть очевидных опечаток. Адекватной проверки орфографии и тем более грамматики для реального 1С-кода здесь сейчас нет: слишком много ложных срабатываний и пропусков на терминах предметной области, аббревиатурах и смешанных идентификаторах.

Именно поэтому диагностика отключена по умолчанию.

### Параметры

| Параметр | Тип | По умолчанию | Описание |
|----------|-----|--------------|----------|
| `minWordLength` | Число | 3 | Минимальное число символов Unicode в слове |
| `userWordsToIgnore` | Строка | "" | Список слов-исключений через запятую |
| `caseInsensitive` | Булево | `false` | Сравнивать `userWordsToIgnore` без учета регистра |

## Примеры

### Неправильно

```bsl
Функция ВаринатыОплаты()
    Сообщить("Атмена");
КонецФункции
```

### Правильно

```bsl
Функция ВариантыОплаты()
    Сообщить("Отмена");
КонецФункции
```

### Важное ограничение

Предметные термины, аббревиатуры, смешанные русско-английские идентификаторы и многие корректные 1С-специфичные слова могут как ошибочно подсвечиваться, так и вообще не обнаруживаться.
