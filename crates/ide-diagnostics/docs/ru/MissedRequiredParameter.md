# Пропущен обязательный параметр метода (MissedRequiredParameter)

## Описание диагностики

В вызове процедуры или функции должно быть не меньше позиций, чем у метода обязательных параметров. Если позиций меньше, платформа отвергает вызов с ошибкой `Недостаточно фактических параметров`. Диагностика отмечает такие вызовы и называет параметры, для которых позиции нет.

Позиция, оставленная пустой между запятыми, ошибкой платформы не является: на её место передаётся `Неопределено`, в том числе для обязательного параметра. Диагностика такой вызов не отмечает. Стандарт #std640 всё же рекомендует не пропускать обязательные параметры: вызываемый метод может быть не готов к `Неопределено`. Эту рекомендацию диагностика не проверяет.

Ограничение: вызов метода этого же модуля, в котором нет ни одного выражения, например `Метод(, )`, считается на одну позицию короче, и его последний параметр отмечается, хотя платформа такой вызов принимает.

## Примеры

Для процедуры с сигнатурой:

```bsl
Процедура УстановитьСтатус(Документ, НовыйСтатус, Комментарий)
```

Неправильно:

```bsl
УстановитьСтатус(ТекущийДокумент); // нет позиций для НовыйСтатус и Комментарий
УстановитьСтатус();                // нет позиций для всех обязательных параметров
```

Правильно:

```bsl
УстановитьСтатус(ТекущийДокумент, "Утверждён", "Готов к отгрузке");
УстановитьСтатус(, "Утверждён", "Готов к отгрузке"); // Документ получит Неопределено
```
