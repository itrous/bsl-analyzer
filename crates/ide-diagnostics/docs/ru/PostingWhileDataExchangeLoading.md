# Режим проведения при записи в режиме загрузки данных (PostingWhileDataExchangeLoading)

## Описание диагностики

Установка признака загрузки данных объекта (`ОбменДанными.Загрузка = Истина`) и последующая запись с режимом проведения всегда завершается исключением во время выполнения. В режиме загрузки платформа допускает только обычную запись, проведение недоступно вовсе.

Замер на платформе 8.3.27.2214, на одном проводимом документе:

- `Д.ОбменДанными.Загрузка = Истина;` и `Д.Записать(РежимЗаписиДокумента.Проведение);` дают исключение «Действие не может выполняться в режиме загрузки данных».
- То же с `РежимЗаписиДокумента.ОтменаПроведения` даёт тот же текст: затронуты оба режима проведения, а не только проведение.
- Тот же `Д.Записать(РежимЗаписиДокумента.Проведение)` без признака загрузки выполняется, документ проводится.
- Признак загрузки вместе с `Д.Записать(РежимЗаписиДокумента.Запись)` выполняется: это допустимое и привычное сочетание, оно никогда не отмечается.

Диагностика срабатывает на вызов `Записать`, если в той же процедуре ту же локальную переменную раньше получила присваивание `Переменная.ОбменДанными.Загрузка = Истина` (литерал `Истина`) в списке операторов, где стоит запись, или в охватывающем его, между ними нет `Переменная.ОбменДанными.Загрузка = Ложь` (и иного присваивания признаку или самой переменной), а аргумент - литерал `РежимЗаписиДокумента.Проведение` или `РежимЗаписиДокумента.ОтменаПроведения`. Всё, что нельзя установить статически, не отмечается: режим из переменной, признак из выражения, получатель сложнее голого имени переменной, признак, установленный только во вложенном блоке.

Чтобы пересчитать движения документа, его нужно записать с режимом проведения отдельной операцией, без признака загрузки.

## Примеры

Неправильно:

```bsl
Док = Ссылка.ПолучитьОбъект();
Док.ОбменДанными.Загрузка = Истина;
Док.Записать(РежимЗаписиДокумента.Проведение);
```

Правильно:

```bsl
Док = Ссылка.ПолучитьОбъект();
Док.ОбменДанными.Загрузка = Истина;
Док.Записать(РежимЗаписиДокумента.Запись);
```
