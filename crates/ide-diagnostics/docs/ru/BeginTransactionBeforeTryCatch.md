# Нарушение правил работы с транзакциями для метода 'НачатьТранзакцию' (BeginTransactionBeforeTryCatch)

## Описание диагностики

Вызов `НачатьТранзакцию()` должен располагаться непосредственно перед оператором `Попытка`, за пределами блока `Попытка-Исключение`. Если между `НачатьТранзакцию()` и `Попытка` возникнет ошибка, транзакция останется открытой и не будет корректно обработана в блоке `Исключение`. Размещение `НачатьТранзакцию()` внутри блока `Попытка` также нарушает стандарт, поскольку при ошибке до начала транзакции код в секции `Исключение` попытается откатить несуществующую транзакцию.

## Примеры

### Неправильно

```bsl
// НачатьТранзакцию внутри блока Попытка
Попытка
    НачатьТранзакцию();
    Документ.Записать();
    ЗафиксироватьТранзакцию();
Исключение
    ОтменитьТранзакцию();
КонецПопытки;
```

### Правильно

```bsl
НачатьТранзакцию();
Попытка
    Документ.Записать();
    ЗафиксироватьТранзакцию();
Исключение
    ОтменитьТранзакцию();
    ВызватьИсключение;
КонецПопытки;
```

Транзакцию можно открывать по условию, если `НачатьТранзакцию()` завершает ветвь `Если`, а сразу после `КонецЕсли` идёт `Попытка`: между началом транзакции и `Попытка` ничего не выполняется.

```bsl
Если СвояТранзакция Тогда
    НачатьТранзакцию();
КонецЕсли;
Попытка
    Документ.Записать();
    Если СвояТранзакция Тогда
        ЗафиксироватьТранзакцию();
    КонецЕсли;
Исключение
    Если СвояТранзакция Тогда
        ОтменитьТранзакцию();
    КонецЕсли;
    ВызватьИсключение;
КонецПопытки;
```
