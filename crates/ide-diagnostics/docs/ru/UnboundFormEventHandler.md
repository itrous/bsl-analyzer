# Несвязанный обработчик события формы (UnboundFormEventHandler)

## Описание диагностики

Платформа подключает обработчик события управляемой формы только через элемент `<Event>` в `Ext/Form.xml`. Имя процедуры в модуле формы ничего не значит: процедура `ПриОткрытии`, на которую не ссылается ни одно событие формы, никогда не вызывается.

Это измерено на платформе 8.3.27.2214: ни ошибки сборки, ни предупреждения, ни исключения во время работы, ни записи в журнале регистрации - заметно только отсутствие эффекта. Поэтому дефект находят по тому, что ожидаемое действие не происходит.

Диагностика сообщает о процедуре или функции, если одновременно выполнено всё:

- модуль принадлежит управляемой форме, у которой нет базовой формы;
- имя метода (без учёта регистра) совпадает с каноническим именем обработчика события самой формы: `ПриСозданииНаСервере`, `ПриОткрытии`, `ПередЗаписью`, `ОбработкаОповещения`, `ОбработкаВыбора`, `ПослеЗаписи` и другие;
- ни одно событие формы и ни одна команда не указывают на этот метод;
- метод не экспортный;
- метод нигде не вызывается в модуле, и его имя не встречается в строковых литералах модуля (обработчики ожидания, оповещения и подключение по имени).

Чаще всего исправление состоит в том, чтобы ДОБАВИТЬ привязку события в форме, а не удалять процедуру: судя по имени, автор рассчитывал, что она работает.

Диагностика намеренно молчит про экспортные методы (их может вызывать другой модуль), формы с базовой формой (обработчики заимствованной формы живут в модуле основной конфигурации), имена вне таблицы обработчиков и обычные (неуправляемые) формы. Одно объявление не получает второго замечания `UnusedLocalMethod`.

## Примеры

Неправильно

```bsl
&НаКлиенте
Процедура ПриОткрытии()
    // событие OnOpen в Form.xml не указывает на эту процедуру
КонецПроцедуры
```

Правильно

```xml
<Events>
    <Event name="OnOpen">ПриОткрытии</Event>
</Events>
```

## Источники

- Замер на платформе 8.3.27.2214: обработчик формы подключается только через `<Event>` в `Ext/Form.xml`, по имени процедуры - никогда.
- Руководство разработчика 1С:Предприятия 8.3 - события управляемой формы и их обработчики.
