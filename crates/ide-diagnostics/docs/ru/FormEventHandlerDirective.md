# Директива обработчика события формы (FormEventHandlerDirective)

## Описание диагностики

Обработчик события управляемой формы, объявленный с директивой компиляции, которая не компилирует его в тот контекст, где событие его вызывает, платформа не подключает: обработчик никогда не выполняется.

Это измерено на платформе 8.3.27.2214: при несовпадении директивы нет ни ошибки сборки, ни предупреждения, ни исключения во время работы - обработчик просто молча не вызывается. Поэтому ошибка обнаруживается только по тому, что ожидаемое действие не происходит.

Нужный контекст зависит от события: например, `ПриСозданииНаСервере` требует `&НаСервере`, `ПриОткрытии` требует `&НаКлиенте`, `ПриПолученииДанныхНаСервере` требует `&НаСервереБезКонтекста`. Имя события берётся из `Ext/Form.xml` формы, привязка к процедуре - по имени обработчика без учёта регистра.

Сообщаются только комбинации, проверенные замером на живой платформе:

- событие требует `&НаСервере`: замечание, если обработчик объявлен с `&НаСервереБезКонтекста`, `&НаКлиенте` или `&НаКлиентеНаСервереБезКонтекста`; допустимы `&НаСервере` и отсутствие директивы;
- событие требует `&НаКлиенте`: замечание, если обработчик объявлен с `&НаСервере` или без директивы;
- событие требует `&НаСервереБезКонтекста`: замечание, если обработчик объявлен с `&НаСервере`, `&НаКлиенте` или без директивы.

Комбинации, поведение которых не измерялось, намеренно не сообщаются. Директиву `&НаКлиентеНаСервере` диагностика не трогает: её в модуле формы уже сообщает `AtClientAtServerFormMethod`.

Диагностика работает только в модуле управляемой формы и пропускает форму, заимствованную расширением (обработчики там живут в модуле формы основной конфигурации). Если одна процедура привязана к нескольким событиям с разными требованиями, она пропускается. Замечание ставится на имя процедуры или функции.

## Примеры

Неправильно

```bsl
&НаКлиенте
Процедура ПриСозданииНаСервере(Отказ, СтандартнаяОбработка)
    // платформа эту процедуру не вызовет
КонецПроцедуры
```

Правильно

```bsl
&НаСервере
Процедура ПриСозданииНаСервере(Отказ, СтандартнаяОбработка)
    // ...
КонецПроцедуры
```

## Источники

- Замер на платформе 8.3.27.2214: обработчик, объявленный с директивой, не соответствующей контексту события, не подключается - без ошибки сборки, предупреждения и исключения.
- Руководство разработчика 1С:Предприятия 8.3, раздел 4.8.1.3 - таблица доступности директив компиляции.
