# Вызов неразрешённого метода (UnresolvedMethodCall)

## Описание диагностики

Диагностика сообщает о квалифицированном вызове метода, который анализатор не смог уверенно разрешить.

Обычно это означает одно из следующих:

- неверно указано имя общего модуля;
- в имени метода есть опечатка;
- метод существует, но не экспортирован;
- в метаданных указан общий модуль, исходный файл которого отсутствует в workspace.

Текущая реализация консервативна и ориентирована на квалифицированные вызовы вида `ОбщийМодуль.Метод()`, где resolver уже способен выдать полезную ошибку.

## Платформенные типы

Вызов метода у значения платформенного типа проверяется только там, где полнота состава членов этого типа подтверждена аттестацией (`type_member_surface_attestations` в `crates/bsl-platform/data/platform_overlays.json`). Такой тип считается закрытым: данных о платформе известно, что они перечисляют все его методы, поэтому вызов отсутствующего метода — ошибка кода, а не пробел в данных.

- тип должен быть аттестован, а версия данных о платформе, которой пользуется анализатор, — не старше версии, на которой состав проверялся; если версию определить нельзя, проверка молчит;
- если имя типа — тёзка (одно имя у двух разных платформенных типов), проверка тоже молчит: неизвестно, какой из них имеется в виду;
- для неаттестованных платформенных типов вызов молчит: полнота их состава не гарантирована.

```bsl
Запись = Новый ЗаписьJSON;
Запись.ЗаписатьНачалоТаблицы(); // <-- у записи JSON нет такого метода
```

## Примеры

Неправильно:

```bsl
ОбщийМодуль.НесуществующийМетод();
```

Правильно:

```bsl
ОбщийМодуль.СуществующийМетод();
```

## Вызов через ЭтотОбъект / ЭтаФорма в модуле формы

Через `ЭтотОбъект` и `ЭтаФорма` доступны только экспортные методы модуля формы. Неэкспортный метод модуль не ломает, но при выполнении вызов падает с ошибкой «Метод объекта не обнаружен» (проверено на 8.3.17 и 8.3.27, на клиенте и на сервере).

Неправильно:

```bsl
&НаКлиенте
Процедура Показать()
КонецПроцедуры

&НаКлиенте
Процедура Сохранить()
    ЭтаФорма.Показать();
КонецПроцедуры
```

Правильно:

```bsl
&НаКлиенте
Процедура Сохранить()
    Показать();
КонецПроцедуры
```

либо объявить метод `Экспорт`.
