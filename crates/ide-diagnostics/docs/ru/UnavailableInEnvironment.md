# Обращение к API, недоступному в контексте исполнения (UnavailableInEnvironment)

## Описание диагностики

Платформенный API доступен не во всех средах исполнения: часть типов, методов, свойств и глобальных функций существует только на сервере, часть — только в отдельных видах клиента (справка платформы описывает это в разделе «Доступность»). Диагностика сообщает об обращении к платформенному члену из кода, который исполняется в среде, где этого члена нет: например, вызов серверного API из метода за директивой `&НаКлиенте` или конструирование `Новый ЧтениеТекста` в коде, компилируемом для веб-клиента.

Множество сред точки вызова вычисляется как пересечение сред модуля (тип модуля, флаги общего модуля: Сервер, КлиентУправляемоеПриложение, ВызовСервера, ВнешнееСоединение) и директивы компиляции метода (`&НаКлиенте`, `&НаСервере`, `&НаКлиентеНаСервере`, …). В квалификаторе сообщения перечисляются только среды, в которых член недоступен — по аналогии с вердиктами 1C:EDT «… is not defined [Web client]».

Проверяются и глобальные коллекции менеджеров объектов конфигурации (`Справочники`, `Документы`, `Перечисления`, `РегистрыСведений`, …): это серверная поверхность, в тонком, веб- и мобильном клиенте таких глобальных свойств нет, и модуль с обращением `Перечисления.<Имя>.<Значение>` там не компилируется. Диагностика ставится один раз — на корневое имя коллекции, независимо от длины цепочки. Клиентская замена — `ПредопределенноеЗначение("Перечисление.<Имя>.<Значение>")`.

Условия препроцессора учитываются: внутри `#Если … #КонецЕсли` проверяется только пересечение сред метода со средами, для которых ветка компилируется (`#Если НЕ ВебКлиент Тогда` снимает веб-клиент, ветка `#Иначе` получает дополнение). Для сред, относительно которых условие невычислимо (например, содержит имя ОС и не разрешается поглощением И/ИЛИ), проверки пропускаются во всей цепочке веток. Это относится и к областям препроцессора вокруг целых методов: метод, объявленный внутри `#Если НЕ ВебКлиент Тогда`, не проверяется относительно веб-клиента.

Модуль обычной формы исполняется только в толстом клиенте: в обычном приложении, а в управляемом — лишь если в основной конфигурации включено свойство «Использовать обычные формы в управляемом приложении» (`UseOrdinaryFormInManagedApplication`). При выключенном свойстве такой модуль не проверяется относительно толстого клиента управляемого приложения; если основной конфигурации нет (проект из одних внешних обработок), учитываются оба толстых клиента.

Текущие ограничения (сознательно консервативные):

- модули расширений (перехватчики `&Вместо`/`&Перед`/`&После`, `&ИзменениеИКонтроль`) не проверяются;
- мобильный клиент, внешнее соединение и толстый клиент (обычное приложение) по умолчанию не входят в проверяемое множество сред (`checked_environments`);
- если имя платформенного типа неоднозначно (например, `ЭлементыФормы` — это и коллекция элементов управляемой формы, и легаси-элементы обычных форм), доступность его членов не проверяется.

## Настройка

Проверяемое множество сред задаётся в `bsl-analyzer.toml` именами в стиле символов препроцессора (регистр не важен, русские и английские имена равнозначны). Конфигурация, не работающая в веб-клиенте, исключает его из списка:

```toml
[features]
checked_environments = ["ТонкийКлиент", "ТолстыйКлиентУправляемоеПриложение", "Сервер"]
```

По умолчанию проверяются тонкий клиент, веб-клиент, толстый клиент (управляемое приложение) и сервер. Указание `МобильныйКлиент` или `ТолстыйКлиентОбычноеПриложение` включает эти среды и в модель исполнения (мобильный клиент добавляется в клиентские среды, обычное приложение — через поддержку обычного приложения). Список из одних нераспознанных имён не меняет набор (предупреждение в лог); явный пустой список `[]` отключает обе проверки. Настройка общая для `UnavailableInEnvironment` и `ModuleAccessibility`.

## Примеры

Неправильно:

```bsl
&НаКлиенте
Процедура ПрочитатьФайл()
    // ЧтениеТекста недоступно в веб-клиенте
    Чтение = Новый ЧтениеТекста;
    Строка = Чтение.ПрочитатьСтроку();
КонецПроцедуры
```

Правильно:

```bsl
&НаСервере
Процедура ПрочитатьФайлНаСервере()
    Чтение = Новый ЧтениеТекста;
    Строка = Чтение.ПрочитатьСтроку();
КонецПроцедуры
```

или с явным сужением среды препроцессором (диагностика понимает такие условия и не сработает):

```bsl
&НаКлиенте
Процедура ПрочитатьФайл()
    #Если НЕ ВебКлиент Тогда
    Чтение = Новый ЧтениеТекста;
    Строка = Чтение.ПрочитатьСтроку();
    #КонецЕсли
КонецПроцедуры
```
