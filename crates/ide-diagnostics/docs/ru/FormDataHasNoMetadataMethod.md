# У данных формы нет метода Метаданные() (FormDataHasNoMetadataMethod)

## Описание диагностики

Реквизит формы, который хранит редактируемый объект (основной реквизит `Объект`), - это не сам объект, а данные формы (`ДанныеФормыСтруктура`). У этого типа нет метода `Метаданные()`, поэтому вызов `Объект.Метаданные()` в модуле управляемой формы завершается ошибкой времени выполнения: `Метод объекта не обнаружен (Метаданные)`.

Замер на платформе 8.3.27.2214, в тонком клиенте, на управляемой форме: `ТипЗнч(Форма.Объект)` даёт `ДанныеФормыСтруктура`, а `Форма.Объект.Метаданные()` отвечает отказом `Метод объекта не обнаружен (Метаданные)`. Тот же текст приходит и на `Форма.Объект.Ссылка.Метаданные()`: `Метаданные()` - метод сервера, у ссылки в тонком клиенте его тоже нет. На сервере его принимают и ссылка (`Справочники.<Имя>.ПустаяСсылка().Метаданные()`), и сам объект.

Поэтому добавить `.Ссылка` недостаточно: метаданные нужно получать на сервере - вызовом `Объект.Ссылка.Метаданные()` в процедуре или функции с директивой `&НаСервере` (либо `Метаданные.<Коллекция>[ИмяОбъекта]`, например `Метаданные.Справочники[ИмяОбъекта]`, когда имя объекта известно) - и передавать на клиент нужное значение, например имя или представление. Вызов `Метаданные()`, оставленный в клиентском коде, отдельно отмечает диагностика `UnavailableInEnvironment` («Метод 'Метаданные' недоступен [Тонкий клиент, Веб-клиент]»), поэтому после переноса вызова в метод с `&НаСервере` исчезают обе находки.

Диагностика срабатывает на вызов `Метаданные` (`Metadata`) без аргументов, у которого тип получателя, определённый анализатором, - данные формы объекта (`ДанныеФормыСтруктура`, в том числе вместе с коллекцией), и только в модуле формы. Проверка идёт по ТИПУ получателя, а не по имени: параметр метода с именем `Объект`, который содержит настоящую ссылку (например, в методе с директивой `&НаКлиентеНаСервереБезКонтекста`), не отмечается. Получатель неизвестного типа и объединение типов тоже не отмечаются. То, как сработает вызов у получателя-ссылки, зависит от того, где он выполняется (см. выше), - диагностика этого не оценивает.

## Примеры

Неправильно:

```bsl
&НаКлиенте
Процедура Проверить()
    ИмяОбъекта = Объект.Метаданные().Имя;
КонецПроцедуры
```

Правильно:

```bsl
&НаСервере
Функция ИмяОбъекта()
    Возврат Объект.Ссылка.Метаданные().Имя;
КонецФункции

&НаКлиенте
Процедура Проверить()
    ИмяОбъекта = ИмяОбъекта();
КонецПроцедуры
```

Не отмечается (параметр содержит настоящую ссылку, а не данные формы):

```bsl
&НаКлиентеНаСервереБезКонтекста
Функция ИмяОбъекта(Объект)
    Возврат Объект.Метаданные().Имя;
КонецФункции
```
