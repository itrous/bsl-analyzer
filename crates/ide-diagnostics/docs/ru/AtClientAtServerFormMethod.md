# Метод формы с директивой &НаКлиентеНаСервере (AtClientAtServerFormMethod)

## Описание диагностики

Метод управляемой формы, объявленный с директивой компиляции `&НаКлиентеНаСервере`, недоступен ни клиенту, ни серверу: вызвать его нельзя ниоткуда.

Это измерено на платформе 8.3.27.2214 (внешняя обработка с управляемой формой, пробный метод вызывается из процедуры с `&НаСервере`): форма не открывается, `ПолучитьФорму` завершается ошибкой «Ошибка инициализации модуля: ... Процедура или функция с указанным именем не определена». Пока вызова нет, форма открывается, то есть само объявление форму не ломает - это мёртвый код, который падает, как только его вызывают.

Директива `&НаКлиентеНаСервереБезКонтекста` в модуле формы допустима: метод с ней виден и клиенту, и серверу. Её диагностика не затрагивает - именно её нужно использовать, когда метод должен быть доступен с обеих сторон.

Диагностика работает только в модуле управляемой формы. Сама директива `&НаКлиентеНаСервере` - часть языка и допустима, например, в модуле команды.

- проверяются процедуры и функции верхнего уровня;
- переменные модуля не проверяются;
- замечание ставится на имя метода.

## Примеры

Неправильно

```bsl
&НаКлиентеНаСервере
Процедура ОбновитьДанные()
    // ...
КонецПроцедуры
```

Правильно

```bsl
&НаКлиентеНаСервереБезКонтекста
Процедура ОбновитьДанные()
    // ...
КонецПроцедуры
```

## Источники

- Руководство разработчика 1С:Предприятия 8.3, раздел 4.8.1.3 - таблица доступности директив компиляции.
- Замер на платформе 8.3.27.2214: метод с `&НаКлиентеНаСервере`, вызванный из `&НаСервере`, даёт ошибку инициализации модуля формы; тот же код с `&НаКлиентеНаСервереБезКонтекста` проходит.
