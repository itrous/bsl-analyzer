# Обработчик оповещения не найден или не экспортный (MissingNotifyHandler)

## Описание диагностики

`Новый ОписаниеОповещения("ИмяОбработчика", Приёмник)` задаёт обработчик строкой. Платформа вызывает его только как ЭКСПОРТНЫЙ метод модуля-приёмника. Если процедура объявлена без `Экспорт` или её нет вовсе (опечатка в строке), код компилируется и проверка модулей проходит; ошибка приходит во время работы модальным окном `Не найден экспортируемый метод: <ИмяОбработчика>`, а в сценарии `ПередЗакрытием` форму после этого невозможно закрыть.

Это измерено на платформе 8.3.17.1549 в модуле управляемой формы.

Диагностика сообщает о регистрации (вызов `Новый ОписаниеОповещения`, а не объявление), если:

- приёмник - `ЭтотОбъект` / `ЭтаФорма`, и модуль не объявляет метод с таким именем либо объявляет его без `Экспорт`;
- приёмник - общий модуль конфигурации, и этот модуль не объявляет метод с таким именем либо объявляет его без `Экспорт`.

Диагностика молчит, когда приёмник не является известным общим модулем (локальная переменная, модуль, которого анализ не видит), когда тело модуля не удалось прочитать (отсутствие не доказано), когда приёмник - не простой идентификатор, и в модулях обычных форм (толстый клиент). Регистрация внутри комментария регистрацией не считается. Обработчики `ПодключитьОбработчикОжидания` и `УстановитьДействие` не проверяются.

## Примеры

Неправильно

```bsl
Процедура ПередЗакрытием()
    Оповещение = Новый ОписаниеОповещения("ЗакрытиеЗавершение", ЭтотОбъект);
КонецПроцедуры

Процедура ЗакрытиеЗавершение(Результат, Параметры) // нет Экспорт
КонецПроцедуры
```

Правильно

```bsl
Процедура ЗакрытиеЗавершение(Результат, Параметры) Экспорт
КонецПроцедуры
```

## Источники

- Измерение на платформе 8.3.17.1549: неэкспортный или отсутствующий обработчик оповещения падает только во время работы с `Не найден экспортируемый метод`.
