# ЗначениеЗаполнено от Булево (ValueIsFilledOfBoolean)

## Описание диагностики

`ЗначениеЗаполнено(X)` отвечает на вопрос, отличается ли значение от значения по умолчанию своего типа. Для типа `Булево` ответ всегда `Истина`: `Ложь` платформа тоже считает заполненным значением. Поэтому условие `Если ЗначениеЗаполнено(Флаг) Тогда` с булевым `Флаг` выполняется всегда и ничего не проверяет; автор почти наверняка имел в виду `Если Флаг Тогда`.

Замер на двух сборках платформы, результаты совпали:

| Выражение | 8.3.17.1549 | 8.3.27.2214 |
|---|---|---|
| `ЗначениеЗаполнено(Истина)` | Да | Да |
| `ЗначениеЗаполнено(Ложь)` | Да | Да |
| `ЗначениеЗаполнено(0)` | Нет | Нет |
| `ЗначениеЗаполнено("")` (пустая строка) | Нет | Нет |
| `ЗначениеЗаполнено(Неопределено)` | Нет | Нет |

Платформа такой вызов принимает без ошибок и предупреждений: функция универсальна и для любого значения законно возвращает «Да» или «Нет», поэтому ошибки компиляции нет, а бессмысленность проверки видна только по типу аргумента.

Диагностика срабатывает на вызов `ЗначениеЗаполнено` с одним аргументом, который является `Булево` по построению: литерал `Истина` или `Ложь`, результат сравнения (`А = Б`), `И`, `ИЛИ`, `Не`, булев реквизит, прочитанный через ссылку на объект метаданных (`Ссылка.Флаг`; у него нет пустого значения, в отличие от поля выборки запроса или строки таблицы значений, где булева колонка может прийти как `NULL`), либо локальная переменная, которой в этой процедуре присваиваются только такие значения, первое присваивание стоит на верхнем уровне процедуры до вызова, а сама переменная не передаётся в другие вызовы (она могла бы получить значение через выходной параметр, как в `Структура.Свойство("Ключ", Переменная)`).

Остальное не отмечается: вывод типа отбрасывает `Неопределено` и неизвестные ветви объединения, поэтому переменная, которая на одном пути `Неопределено`, а на другом получает булево значение, или результат функции, возвращающей и булево, и неизвестное, выглядят как чистое `Булево`, хотя проверка для них осмысленна. Не отмечаются также составной тип, в который `Булево` лишь входит, значение неизвестного типа, параметр, переменная модуля, поле выборки запроса, строки таблицы значений или структуры, поле с получателем неизвестного типа, индекс и результат вызова.

## Примеры

Неправильно:

```bsl
Если ЗначениеЗаполнено(ФлагВыполнено) Тогда
    ЗапуститьОбработку();
КонецЕсли;
```

Правильно:

```bsl
Если ФлагВыполнено Тогда
    ЗапуститьОбработку();
КонецЕсли;

Если Не ФлагВыполнено Тогда
    ПодготовитьОбработку();
КонецЕсли;
```
