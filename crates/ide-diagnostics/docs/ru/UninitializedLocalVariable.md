# Неинициализированная локальная переменная (UninitializedLocalVariable)

## Описание диагностики

Диагностика отмечает чтение неявной локальной переменной, до которого хотя бы на одном возможном
пути выполнения переменной не присвоено значение. Такая переменная на этом пути содержит
`Неопределено`. Присваивание в теле цикла не инициализирует переменную для чтения, выполненного
раньше на первой итерации; присваивание только в части веток условия не инициализирует её для
остальных веток.

Сообщение называет путь, на котором значение не присвоено: первая итерация цикла, цикл, который
может не выполниться ни разу, ветвь условия или иной путь.

Неправильно:

```bsl
Процедура Обработать()
    Для Номер = 1 По 2 Цикл
        Копия = ПозднееЗначение;
        ПозднееЗначение = 7;
        Сообщить(Копия);
    КонецЦикла;
КонецПроцедуры
```

Правильно:

```bsl
Процедура Обработать()
    ПозднееЗначение = 0;
    Для Номер = 1 По 2 Цикл
        Копия = ПозднееЗначение;
        ПозднееЗначение = 7;
        Сообщить(Копия);
    КонецЦикла;
КонецПроцедуры
```

## Границы анализа

Диагностика проверяет только неявные локальные переменные — те, что появляются присваиванием, и
переменные циклов `Для` и `Для Каждого`. Анализ не выполняет код и не вычисляет условия, кроме
заголовков `Пока Истина` и `Для` с числовыми границами-литералами. Не сообщается:

- о параметре метода;
- о переменной, объявленной `Перем`;
- о переменной модуля и других именах, которыми владеет модуль, форма или объект;
- о чтении после вызова, в который переменная передана аргументом и о котором не известно, что
  параметр объявлен `Знач`: такой вызов может присвоить ей значение;
- о чтении после оператора `Выполнить`, который может присвоить значение любой переменной;
- в методе с неполным графом потока управления: ошибка разбора, восстановленный оператор,
  `Перейти` без метки или анализ, не уложившийся в предел итераций.
