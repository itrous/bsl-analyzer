# Изменение реквизитов объекта в обработчике ПриЗаписи (ObjectModifiedInOnWrite)

## Описание диагностики

Стандарт #std465 гласит: «Запрещается в данном обработчике изменять содержимое записываемого объекта, поскольку на момент выполнения обработчика, объект уже записан в БД.»

Присваивание реквизиту или табличной части самого объекта в обработчике `ПриЗаписи` модуля объекта не попадёт в базу данных: объект уже записан. Заполнять реквизиты объекта нужно в обработчике `ПередЗаписью` (#std464).

Диагностика срабатывает на присваивание имени, которое является реквизитом, общим реквизитом или табличной частью самого объекта (`Склад = ...` или `ЭтотОбъект.Склад = ...`). Не считаются нарушением: параметры процедуры, переменные, объявленные через `Перем` в теле процедуры, и переменные циклов `Для` / `Для Каждого` (они перекрывают реквизит; запись через `ЭтотОбъект.Склад` при этом всё равно считается нарушением), свойства платформы (`ДополнительныеСвойства`, `Движения`, `ОбменДанными`) и запись данных ДРУГИХ объектов: именно для этого обработчик `ПриЗаписи` и предназначен.

Стандартные реквизиты (`Наименование`, `Код`, `Дата`, `Номер`) диагностика пока не видит.

## Примеры

Неправильно:

```bsl
Процедура ПриЗаписи(Отказ)

    Склад = ПолучитьСкладПоУмолчанию();

КонецПроцедуры
```

Правильно:

```bsl
Процедура ПередЗаписью(Отказ)

    Склад = ПолучитьСкладПоУмолчанию();

КонецПроцедуры
```
