# Виртуальная таблица регистра расчёта без отбора по регистратору (CalculationRegisterVirtualTableWithoutRecorder)

## Описание диагностики

Виртуальные таблицы регистра расчёта `ДанныеГрафика`, `ФактическийПериодДействия` и `База<Регистр>` без отбора строятся по всем записям регистра, и для каждой записи платформа вычисляет значения. При расчёте нужны только записи рассчитываемого набора, поэтому в параметре-условии таблицы ставится отбор по регистратору.

Диагностика отмечает обращение, в параметре-условии которого нет отбора по `Регистратор` (`Recorder`). Параметр-условие — первый параметр у `ДанныеГрафика` и `ФактическийПериодДействия` и четвёртый у `База<Регистр>`.

Отбором считается:

- сравнение `Регистратор = <выражение>` в любую сторону;
- `Регистратор В (<список>)`;
- такое сравнение как часть условия, связанного через `И`, в том числе в скобках.

Отбором не считается: условие в `ГДЕ` запроса, отбор по другому полю, `<>` и другие сравнения, `НЕ`, `В ИЕРАРХИИ`, сравнение только под `ИЛИ` (в том числе `Регистратор = &А ИЛИ Регистратор = &Б`), поле через точку `Регистратор.Номер`.

Список параметров, который модуль дописывает при выполнении (`"…ДанныеГрафика(" + Условие + ")"`), и условие, заданное только расширением системы компоновки `{...}`, диагностика не судит: условие неизвестно, а не отсутствует.

Таблица `База<Регистр>` узнаётся по имени, начинающемуся на `База` (`Base`). Перерасчёт с таким именем тоже будет проверен как таблица базы.

## Параметры

- `onlyInModulesWritingRegister` — если `true`, в модуле срабатывание остаётся, только если модуль пишет этот же регистр: в нём есть `Движения.<Регистр>` или `RegisterRecords.<Name>` (на любом получателе, например `ЭтотОбъект.Движения.<Регистр>`). Так отчёты, которым отбор по регистратору не нужен, не отмечаются. `Движения["<Регистр>"]` и упоминание в комментарии записью не считаются; ветки препроцессора не вычисляются. Текст запроса без модуля параметр не ограничивает. По умолчанию `false` — решает только текст запроса.

## Примеры

### Срабатывание

```bsl
Запрос.Текст =
"ВЫБРАТЬ
|	ДанныеГрафика.НомерСтроки КАК НомерСтроки
|ИЗ
|	РегистрРасчета.Начисления.ДанныеГрафика(ВидРасчета = &ВидРасчета) КАК ДанныеГрафика";
```

### Предпочтительно

```bsl
Запрос.Текст =
"ВЫБРАТЬ
|	ДанныеГрафика.НомерСтроки КАК НомерСтроки
|ИЗ
|	РегистрРасчета.Начисления.ДанныеГрафика(Регистратор = &Регистратор) КАК ДанныеГрафика";
```

## Источники
