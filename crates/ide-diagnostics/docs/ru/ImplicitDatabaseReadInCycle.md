# Неявное чтение из базы в цикле (ImplicitDatabaseReadInCycle)

## Описание диагностики

Диагностика отмечает статические кандидаты на чтение из базы данных в теле цикла:
обращение к реквизиту через точку от ссылки, получение представления ссылки через `Строка()`
и поиск менеджера методом `НайтиПо*`. Получите необходимые значения одним запросом до цикла.

### Через точку от ссылки

Обращение к реквизиту объекта через точку от ссылки загружает объект. Выберите нужные реквизиты
в запросе до цикла.

Неправильно:

```bsl
Запрос = Новый Запрос;
Запрос.Текст = "ВЫБРАТЬ Т.Ссылка КАК Номенклатура ИЗ Справочник.Товары КАК Т";
Выборка = Запрос.Выполнить().Выбрать();

Пока Выборка.Следующий() Цикл
    Наименование = Выборка.Номенклатура.Наименование;
    Артикул = Выборка.Номенклатура.Код;
КонецЦикла;
```

Правильно:

```bsl
Запрос = Новый Запрос;
Запрос.Текст = "ВЫБРАТЬ Т.Наименование КАК Наименование, Т.Код КАК Артикул ИЗ Справочник.Товары КАК Т";
Выборка = Запрос.Выполнить().Выбрать();

Пока Выборка.Следующий() Цикл
    Наименование = Выборка.Наименование;
    Артикул = Выборка.Артикул;
КонецЦикла;
```

### Представление ссылки через `Строка()`

`Строка(Ссылка)` получает представление ссылки. Если оно нужно в цикле, выберите его в запросе
до цикла с помощью `ПРЕДСТАВЛЕНИЕ`.

Неправильно:

```bsl
Для Каждого Ссылка Из Ссылки() Цикл
    Представление = Строка(Ссылка);
КонецЦикла;
```

Правильно:

```bsl
Запрос = Новый Запрос;
Запрос.Текст = "ВЫБРАТЬ ПРЕДСТАВЛЕНИЕ(Т.Ссылка) КАК ТоварПредставление ИЗ Справочник.Товары КАК Т";
Выборка = Запрос.Выполнить().Выбрать();

Пока Выборка.Следующий() Цикл
    Представление = Выборка.ТоварПредставление;
КонецЦикла;
```

### Поиск менеджера

Методы менеджера `НайтиПоКоду`, `НайтиПоНаименованию`, `НайтиПоНомеру` и `НайтиПоРеквизиту`
выполняют поиск в базе. Если нужно обработать много значений, найдите их одним запросом до цикла.

Неправильно:

```bsl
Для Каждого Код Из Коды Цикл
    Товар = Справочники.Товары.НайтиПоКоду(Код);
    ОбработатьТовар(Товар);
КонецЦикла;
```

Правильно:

```bsl
Запрос = Новый Запрос;
Запрос.Текст =
    "ВЫБРАТЬ Т.Ссылка КАК Товар " +
    "ИЗ Справочник.Товары КАК Т " +
    "ГДЕ Т.Код В (&Коды)";
Запрос.УстановитьПараметр("Коды", Коды);
Выборка = Запрос.Выполнить().Выбрать();

Пока Выборка.Следующий() Цикл
    ОбработатьТовар(Выборка.Товар);
КонецЦикла;
```

## Границы анализа

Диагностика анализирует только выражения в лексическом теле цикла текущего метода. Рекурсивный или
циклический вызов, а также вызов с недоступным телом, сам по себе не является доказательством чтения
из базы. Тело вызываемого метода не разворачивается в точке вызова; оно анализируется отдельно, по
собственным циклам.

Условия срабатывания зависят от семейства:

- Для чтения реквизита через точку база выражения должна иметь известный тип объектной ссылки.
  `Unknown`, `Any`, число и строка не дают кандидата.
- Для `Строка(Ссылка)` аргумент должен иметь известный тип объектной ссылки, а вызов должен быть
  разрешён как встроенный платформенный вызов. `Unknown`, `Any`, число и строка, а также одноимённая
  пользовательская функция не дают кандидата.
- Для поиска менеджера получатель должен иметь тип `ObjectManager`, а вызов — связываться с
  методом платформы. Тип результата поиска не обязан быть типом ссылки; одноимённый пользовательский
  метод не даёт кандидата.

Это статический кандидат: диагностика не утверждает, что платформа выполнит ровно один запрос к базе на каждой итерации — кэширование и реальные планы запросов требуют измерений.
