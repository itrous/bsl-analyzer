`package.sdbl` — обезличенная структура шестизапросного пакета: пять запросов
создают временные таблицы, последний содержит вложенный `ВЫБРАТЬ РАЗРЕШЕННЫЕ`.
Имена символов заменены по ролям AST, значения строк скрыты, комментарии удалены.
Нетривиальные узлы и виды токенов исходного и обезличенного пакета совпадают.
Синтаксическое совпадение не доказывает равенство результатов на данных платформы.

Тесты направляют этот пакет через настоящий MCP SDK и onec-client в локальный
HTTP-сервер. Сервер получает заранее заданный ответ для каждого контрольного текста;
он не реализует семантику SDBL. Проверяются доставка ошибки HTTP 500 и её текста,
корректный ответ, отказ до HTTP, отмена и отсутствие повторной отправки.

Проверка HTTP timeout использует существующие часы Tokio: после приёма запроса
сервером время продвигается на 31 секунду, чтобы сработал действующий лимит клиента
30 секунд. Отдельная ограниченная задача сервера может продолжаться после потери
HTTP-соединения. Это контроль неопределённого исхода, а не обещание остановки
или rollback на платформе.

Тесты не подключаются к 1С и не повторяют историческое исполнение. Они не доказывают
устранение зависания в исходном broker/HTTP/platform окружении.
